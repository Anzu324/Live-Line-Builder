# パッケージの役割
Live Line Builderはかなり多くのパッケージに分割されている。そのパッケージごとの主な機能についてここに記す。
# domain
EntityなどのPySide6を使用するuiからは切り離されたアプリのデータ保持システムや計算ロジックがある。独自の実装が多いので、単体テストができるように心がける。
# ui
PySide6を使用するui関連のファイル群が置いてある。
## model
domain中にあるEntity等をui側がアクセスするときはこの中にあるModelを通して使用する。
ModelのなかでもDataManagerはデータ管理といったUIから独立した分野においてアプリ全体をつなげる役割を持っている。
DataManagerなどは特段uiが無くても単独で動作する用実装する。
## Proxies
プロキシはTableModelなどはフィルタリングなどの整形を行ったものを最終出力とすることから、経由することでModelそのものを成形する機能を要する。
## view
実際にウィンドウなどを描画する機能。本当はQt Designerを使いたいが、今のところ全てコードで書いている。Viewとは言ってもUIロジックも配置される。
## controller
AppContorollerでは収まらない部分に関しては実装している。あまり大がかりなことはやらない。
# strages
JSONとの相互変換やzip化ファイル保存・読み込みに関する機能を配置する。
# app_mock
.pyで書かれたモックデータを置いている。場所については要検討であるがひとまずこちらに置いている。
