
# 関心領域群

## 機材関連

| 日本語名        | 英語名                     | 意味                                                                                                    |
| ----------- | ----------------------- | ----------------------------------------------------------------------------------------------------- |
| 機材          | Equipment               | マイクやミキサーアンプなどライブで使用するあらゆる装置の総称。                                                                       |
| ポート         | Port                    | Equipmentに属する信号を送信又は受信を行う機能の識別子。互いにケーブル等を用いて接続できる。現時点では有線を想定している。                                     |
| コネクタ        | Connector               | ポートの信号規格及び物理的形状。あまり厳格に実装しないかもしれない。                                                                    |
| マルチ         | Multi                   | マルチは基本的に1の入力に1の出力が可能である。複数のチャンネルをまとめて長距離を伝送する機材。ケーブルの一種であるが配線が極めて煩雑であることから機材の一種とみなす。                  |
| ミキサー        | Mixer                   | ミキシングコンソールともいう。入ってきた音声を混ぜて出力へ伝送する装置。よって出力から入力へ1対1対応を捕捉できなくなり、ここが源流と見做されることに留意。                        |
| マイク         | Microphone              | マイク自体はただ収音した音声を電気信号に変えて出力する装置です。このシステム内部では音も信号そのものと捉え楽器までたどれるようにするため、マイクは入力を持つことができます。よって仕様は入力1出力1です。 |
| 音響パッチシステム| Audio Patch System| 公演ごとのパッチ情報が記述されたシステム全体。|
## 資料関連

| 日本語名        | 英語名                     | 意味                                                                                                    |
| ----------- | ----------------------- | ----------------------------------------------------------------------------------------------------- |
| ライブ情報       | LiveInfo                | ライブ名や会場・日程、裏方情報など。                                                                                    |
| セットリスト(セトリ) | Set List                | ライブの進行表です。軽音の場合は主に楽曲で識別する形になると思います。                                                                   |
| 舞台図         | Stage Plot              | 舞台そのものの図です。ざっくりどこにどの機材を置くのか書いてあります。                                                                   |
| 音響回線表       | Input List              | どの回線を何処に挿すのかパッと見られる表です。大抵マルチ基準やミキサー基準で用意します。                                                          |
| 音響仕込み図      | Input List & Stage Plot(Plan Sheet ) | 舞台図や回線表を含めた印刷用の資料です。                                                                                  |
| 公演          | Performance             | その期間に開かれる個々の開演から終演まで一連の流れを指す。例えば日程・会場等で区切られる。                                                         |

# 実装設計群

| 日本語名      | 英語名          | 意味                                                     |
| --------- | ------------ | ------------------------------------------------------ |
| ドメイン      | Domain       | 純粋なPythonを基調とした独立したコード群。                               |
| UI(ユーアイ)  | UI           | ユーザーへの情報提供・操作受付を担うコード。Qtを用いて実装されている。                   |
| モデル       | Model        | UIそのものと内部のドメイン群を中継するUI用の窓口。Qt独自のシグナルスロットの処理も行う。        |
| データマネージャー | Data Manager | Entityを管理したり、ファイルを読み込んだり、Entity間の整合性に関わる処理を代行したりする。    |
| ビュー       | View         | UIの処理が書かれている部分。UIそのものとは限らずQtデザイナーで作成したものを単に読んでいる場合もある。 |
| コントローラー | Controller  | ViewとModelを結合して表示を完成させる部分を担う。担当のViewやModel自体は外部で生成され渡される。 |
| エンティティ | Enity | ドメイン層にありシステム内部の最も単純かつ基本的なデータ構造。 |
| スキーマ| Schema | 保存時にEntityとJSONとの仲介を行うDTO。※現時点で保存以外にスキーマはつかない。Pydanticを用いて実装されている。Schemaと外部との接続部分のみが知っている。 |
| リポジトリ | Repository | EntityとSchema間の窓口。EntityとSchemaの双方に依存する。 |

## ドメインオブジェクト・モデル
- **機材定義 (EquipmentDefinition)**: 
  メーカー名、型番、ポート構成、機材内部ルーティング（InternalLink）、持ち込み上限数（max_quantity）を保持する「型（ひな形）」。旧 Master / Entity。
- **機材インスタンス (EquipmentInstance)**: 
  現場（公演パッチグラフ内）に実際に配置された「実体（ノード）」。1つの機材定義を参照し、現場固有の識別名（レーベル）や各ポートの状態を保持する。
- **内部リンク (InternalLink)**: 
  機材内部のポート間接続定義（例: DIのINPUT ➜ THRU、ミキサーのCh ➜ Direct Out等）。
- **回線経路 (SignalPath)**: 
  起点（音源/マイク）から終点（卓/スピーカー）までの信号通過順序を表現する順序付きノードリスト（中間データ表現）。

## パッチ・接続
- **直結接続 (Direct Connection)**: 規格・コネクタ形状・性別が完全一致する接続。
- **変換接続 (Adapted Connection)**: コネクタ形状や規格が異なるが、アダプター/変換ケーブル（XLR ↔ BTS等）を介して成立している接続 (`is_adapted=True`)。
- **軟的上限 (Soft Limit)**: 機材配置数が `max_quantity` を超えた際に処理を中断せず、警告（Warning）のみを発行する運用仕様。

## ビュー・表示
- **機材グループビュー**: 特定の機材（ミキサーやマルチ等）の固定ポート順を主軸とした仕込み図用テーブル。
- **舞台側全体ビュー**: マルチのCh順を基本軸としつつ、同一音源の関連回線（モニター等）をメインPA送りの直後に割り込ませ（Interleaving）て描画する配線接続表。
